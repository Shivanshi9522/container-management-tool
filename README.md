# Container Management Tool

Web dashboard to start, stop, and monitor Docker containers using Docker SDK for Node.js.

### Features
- List all containers with status, image, ports
- Start, stop, restart containers 
- View real-time logs and CPU/Memory stats

### Tech Stack
`Node.js` `Express.js` `Docker SDK` `Docker` `REST API` `JavaScript`

### Setup
1. `git clone https://github.com/Shivanshi9522/Contained`
2. `cd backend && npm install`
3. `node server.js`
4. Open `http://localhost:3000`
